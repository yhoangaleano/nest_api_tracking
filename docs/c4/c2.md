# C2: Diagrama de contenedores del sistema

**Estado:** Aceptado
**Fecha:** 2025-11-18

## 1. Descripción

Este diagrama de nivel 2 (contenedores) hace "zoom" dentro de la caja negra del **Sistema de tracking logístico**. Muestra las principales unidades desplegables (contenedores) que interactúan para entregar la funcionalidad.

Visualiza la arquitectura monolítica síncrona, donde una única API maneja todas las responsabilidades de negocio, interactuando directamente con la base de datos y el caché.

## 2. Diagrama (Mermaid)

```mermaid
%%{ init : { "theme" : "default" } }%%
C4Container
    title "Diagrama de contenedores (C2) del sistema de tracking"

    Person(operador, "Operador logístico", "Escanea paquetes")
    Person(cliente, "Cliente", "Consulta su envío")
    Person(admin, "Administrador", "Monitorea la operación")

    System_Boundary(tracking_system, "Sistema de tracking logístico") {

        Container(api, "API monolítica", "NestJS / Docker", "Recibe peticiones HTTP, aplica lógica de negocio y persiste datos de forma síncrona.")
        
        ContainerDb(db, "Base de datos", "PostgreSQL", "Almacena el estado y el historial de los envíos.")
        
        ContainerDb(cache, "Caché", "Redis", "Almacena en caché las consultas de lectura para mejorar el rendimiento.")
    }

    %% --- Relaciones ---

    %% 1. Actores -> API
    Rel(operador, api, "Envía checkpoint", "JSON/HTTPS")
    Rel(cliente, api, "Consulta tracking", "JSON/HTTPS")
    Rel(admin, api, "Consulta estados", "JSON/HTTPS")

    %% 2. Flujo síncrono de datos
    Rel(api, db, "Lee y escribe", "TypeORM")
    Rel(api, cache, "Lee y escribe para cachear", "node-redis")
```
