# C1: Diagrama de contexto del sistema

**Estado:** Aceptado
**Fecha:** 2025-11-12

## 1. Descripción

Este diagrama de nivel 1 (contexto) presenta una visión de alto nivel del **Sistema de tracking logístico**. Muestra el sistema como una "caja negra", enfocándose en sus interacciones con los usuarios (actores).

## 2. Diagrama (Mermaid)

```mermaid
%%{ init : { "theme" : "default" } }%%
C4Context
    title "Diagrama de contexto (C1) del sistema de tracking logístico"

    Person(operador, "Operador logístico", "Empleado que escanea paquetes PDA/móvil")
    Person(cliente, "Cliente", "Destinatario final que consulta su envío")
    Person(admin, "Administrador (backoffice)", "Usuario interno que monitorea la operación")

    System(tracking_api, "Sistema de tracking logístico", "Procesa checkpoints y consultas (nuestro sistema)")

    %% Relaciones de los actores con el sistema
    Rel(operador, tracking_api, "Envía checkpoints", "JSON/HTTPS")
    Rel(cliente, tracking_api, "Consulta historial de tracking", "JSON/HTTPS")
    Rel(admin, tracking_api, "Consulta unidades por estado", "JSON/HTTPS")
```
