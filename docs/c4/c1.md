# C1: Diagrama de contexto del sistema

**Estado:** Aceptado
**Fecha:** 2025-11-18

## 1. Descripción

Este diagrama de nivel 1 (contexto) presenta una visión de alto nivel del **Sistema de tracking logístico**. Muestra el sistema como una "caja negra", enfocándose en sus interacciones con los usuarios (actores) y los sistemas de almacenamiento de datos que utiliza.

## 2. Diagrama (Mermaid)

```mermaid
%%{ init : { "theme" : "default" } }%%
C4Context
    title "Diagrama de contexto (C1) del sistema de tracking logístico"

    Person(operador, "Operador logístico", "Empleado que escanea paquetes con PDA/móvil.")
    Person(cliente, "Cliente", "Destinatario final que consulta el estado de su envío.")
    Person(admin, "Administrador de operaciones", "Usuario interno que monitorea la operación y gestiona envíos.")

    System(tracking_api, "Sistema de tracking logístico", "API monolítica que procesa checkpoints y consultas de forma síncrona.")

    SystemDb(postgres, "Base de datos principal", "PostgreSQL", "Almacena el estado y el historial de todos los envíos.")
    SystemDb(redis, "Caché de lecturas", "Redis", "Almacena en caché las consultas frecuentes para acelerar las respuestas.")

    %% Relaciones de los actores con el sistema
    Rel(operador, tracking_api, "Envía checkpoints", "JSON/HTTPS")
    Rel(cliente, tracking_api, "Consulta historial de tracking", "JSON/HTTPS")
    Rel(admin, tracking_api, "Consulta unidades por estado", "JSON/HTTPS")

    %% Relaciones del sistema con las bases de datos
    Rel(tracking_api, postgres, "Lee y escribe datos de envíos", "TCP/IP")
    Rel(tracking_api, redis, "Lee y escribe datos en caché", "TCP/IP")
```
